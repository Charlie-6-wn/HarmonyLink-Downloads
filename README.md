# HarmonyLink Downloads

HarmonyLink 是 HarmonyOS 手机与 Mac 之间的局域网互联工具。

## 当前状态

0.5.1 处于开发验证阶段，尚未正式发布。华为应用尝鲜草稿已创建，未提交审核；手机安装包暂未公开提供。

Mac 候选包为开发用 ad-hoc 签名，尚未获得 Developer ID 签名及公证。首次 TLS 身份已支持自动准备，完整真机验收仍待完成，不能视为面向普通用户的免配置安装版本。

## 功能范围

扫码配对、前台文字与文件互传（单文件20MiB以内）、Mac设备状态及前台查找手机。实验性无音频屏幕共享尚未完成真机出画面验收，华为账号服务尚未开通。

正式下载包就绪后会通过本仓库 Releases 分发。此仓库不包含开发者私钥、证书身份或配对凭据。
