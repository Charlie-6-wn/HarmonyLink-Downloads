# HarmonyLink Downloads

HarmonyLink 是 HarmonyOS 手机与 Mac 之间的局域网互联工具。

## 当前状态

0.5.1 手机尝鲜测试已于2026年11月14日提交华为，当前预审中，尚未审核通过。测试计划100人，11月18日至12月2日。只有平台审核通过并开放测试后，才能通过官方应用市场安装；无需开发者选项。

[Mac 0.5.1 开发预览版](https://github.com/Charlie-6-wn/HarmonyLink-Downloads/releases/tag/v0.5.1) 已公开。仅Apple Silicon arm64、macOS13+，ad-hoc开发签名，尚无Developer ID签名及公证。若系统阻止运行，请反馈签名限制，不关闭系统安全保护。

## 功能范围

扫码配对、前台文字与文件互传（单文件20MiB以内）、Mac设备状态及前台查找手机。实验性无音频屏幕共享尚未完成真机出画面验收，华为账号服务尚未开通。首次TLS身份可自动准备；实体扫码、文件选择保存、物理响铃和后台行为仍待验收。
